# 🛒 Online Shopping System

An efficient and user-friendly **Java Desktop Application** designed for seamless online shopping experience. Built using **Java Swing** for the UI and integrated with a simple backend logic for managing products, user orders, and shopping cart functionality. Ideal for small-scale e-commerce platforms.

## 🎯 Features

### 🛍️ Shopping Experience
- Browse products with categories
- Add products to the shopping cart
- View product details

### 💳 Order Management
- Create, view, and manage orders
- Update cart items and quantity
- Checkout process with order confirmation

### 🧑‍🤝‍🧑 User Management
- Simple user authentication
- User profiles and order history

### 🎨 UI/UX
- User-friendly interface built with Java Swing
- Responsive layout for better user experience

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/online-shopping-system.git
cd online-shopping-system
```

### 2. Setup Instructions
Make sure you have JDK 8 or higher installed.

### 3,  Compile and Run the Application
```bash
# Navigate to the project folder and compile the Java files
javac -d bin src/*.java

# Run the application
java -cp bin com.yourpackage.Main
```
